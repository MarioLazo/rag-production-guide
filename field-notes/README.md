# Field Notes

Dated, append-only write-ups from actual builds. Each entry is a snapshot of
what happened, what broke, and what it cost, not current best practice.

**These are never edited after publication.** A dated note can't go stale
because it never claimed to be current. Where a later entry contradicts an
earlier one, that's the useful part.

New notes appear when something worth writing up actually happens. There is no
publication schedule, deliberately.
